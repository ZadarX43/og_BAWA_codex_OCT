# PRICING_TIER_STRATEGY_AND_COPY_PLAN

Updated: `2026-05-05`

## Purpose

This document defines the next-stage Odds Genius pricing ladder and the copy strategy needed to present it clearly on the website.

It covers:

- final tier definitions
- founder positioning
- feature matrix direction
- website copy recommendations
- guardrail wording for `for life` and grandfathered access

This is a product and commercial planning document.
It does not change Worker auth, Stripe architecture, or model logic.

## Core Commercial Position

Odds Genius should not sell itself like a discount betting membership.

It should sell:

- access to intelligence
- access to system quality
- access to a controlled deployment layer
- access to increasingly advanced product surfaces over time

The tier ladder should feel like:

- public preview
- founder access
- serious analyst tier
- advanced control tier

Not:

- cheap tipster
- slightly better tipster
- expensive tipster

## Recommended Tier Ladder

## 1. Free

### Purpose

Acquisition and trust-building.

### Position

Public preview of the system.

### What it should include

- limited public board
- rounded confidence
- rounded value-edge display
- proof / results access
- methodology access

### What it should not include

- full deployable board
- shortlist support
- deep model context
- subscriber-only premium context

### Website framing

> Start free. See the signal. Upgrade for the full edge.

## 2. OG Founder

### Price

- `£20/month`

### Capacity

- first `250` users only

### Purpose

Early cohort acquisition and long-term loyalty.

### Position

Founding access to the product before the long-term tier ladder fully expands.

This should feel:

- scarce
- privileged
- permanent while active
- commercially generous
- strategically valuable

### Recommended promise

OG Founder should be positioned as:

- fixed founder pricing while active
- grandfathered founder status
- early access to selected future systems
- more than the eventual base `£20` tier
- less than a full unlimited “everything forever” promise

### What it should include

- full deployable board
- ELITE and STANDARD signals
- full value-edge layer
- correct score shortlist support
- acca safety indicators
- Worker-protected premium access
- early access to new markets
- early access to selected advanced systems
- selected founder grandfathering as the product matures

### What it should not promise

- all future Pro or Pro Plus features forever
- unlimited enterprise-grade access
- all future products at no extra charge

### Recommended website framing

> OG Founder  
> First 250 users.  
> £20/month for life while active.  
> Grandfathered pricing, founder-only upside, and early access to selected advanced systems.

## 3. Pro

### Price

- `£49/month`

### Purpose

Main long-term serious-user plan.

### Position

This is the core commercial plan for users who want more than the founder-era premium shell and need a fuller intelligence workspace.

### What it should likely include

- everything in core premium board access
- richer market coverage
- deeper signal context
- stronger proof / diagnostics visibility
- more advanced board filtering
- earlier access to feature expansions than standard users

### Product intent

Pro should eventually become:

- the main “serious bettor / analyst” product tier
- the place where advanced but still broad-use product features live

### Website framing

> Pro  
> The full analyst-grade intelligence layer for users who want deeper edge context, expanded tools, and more control.

## 4. Pro Plus

### Price

- `£99/month`

### Purpose

Highest-access retail tier before true B2B / syndicate / API products.

### Position

Pro Plus should feel like:

- advanced
- more controlled
- more diagnostic
- more workflow-oriented

Not just “Pro but more expensive.”

### What it could include later

- advanced control layer
- richer diagnostics
- deeper signal-state visibility
- priority access to new tools
- higher-intensity workflow features
- early access to agent / auditor / specialist systems

### Important recommendation

Do not overspec Pro Plus on the public website until the actual product scope is clearer.

It is acceptable to:

- define it internally now
- mention it lightly later
- launch it only when the features genuinely justify it

## Recommended Launch Order

Best commercial rollout:

1. Free
2. OG Founder
3. Pro later
4. Pro Plus later

Why:

- simpler conversion
- stronger founder scarcity
- less pricing confusion
- protects product truth
- avoids inventing feature bloat too early

## Founder Guardrails

The phrase `for life` is strong and useful, but it must be qualified carefully.

### Recommended meaning

`£20/month for life while active`

This means:

- the price stays fixed while the member maintains an active subscription
- the founder benefit is lost if the subscription is cancelled or lapses
- founder status is non-transferable

### Recommended legal / product guardrails

Use wording like:

- while subscription remains active
- non-transferable
- subject to applicable platform terms
- applies to the Founder plan only
- selected future founder benefits may evolve as the product matures

### Do not use

- unlimited forever access to all future systems
- lifetime access with no active-subscription qualifier
- vague “everything we ever build is included”

## Grandfathering Strategy

Founder grandfathering should be framed as:

- selected feature upside
- priority access
- favorable access economics

Not:

- universal entitlement to all future premium and professional products

### Recommended founder grandfathering model

Founder users keep:

- fixed `£20/month` price while active
- the core full deployable board
- early access to new markets
- early access to selected advanced systems
- selected hybrid benefits above the eventual standard `£20` tier

This gives you room later to create:

- a normal `Premium`
- `Pro`
- `Pro Plus`

without breaking the founder promise.

## Messaging Rules

Every pricing page line should reinforce:

- this is intelligence access
- this is controlled deployment
- this is not gambling fluff

### Good language

- deployable board
- value edge
- signal depth
- protected access
- early systems
- advanced markets
- diagnostics
- control layer

### Avoid

- win big
- bet smarter
- huge guaranteed wins
- insider lock
- gambling hype language
